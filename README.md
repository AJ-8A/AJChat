# AJChat — Pro Luxury

An original realtime messaging experience with a **Pro Luxury** interface.

Deep midnight glass · Champagne gold accents · Refined motion · Private · Fast · Global

## Live

**https://aj-8a.github.io/AJChat**

## Design

- **Pro Luxury theme** — midnight black base, champagne gold highlights, soft emerald secondary
- Premium typography (Outfit + Inter)
- Advanced glassmorphism with depth, soft film grain, and ambient glows
- Nature scenery chat background (forest + sakura) kept as atmospheric layer
- Smooth micro-interactions, focus rings, and selection styles
- Fully responsive (desktop + mobile)
- Light / dark theme toggle

## Features

- Realtime chat (Cloudflare Workers + Durable Objects + D1)
- Global community room
- Friend requests & private messaging
- Voice / video calls
- Profile, status, bio
- Chat history search
- Push notification support
- Admin dashboard (matching luxury styling)

## Stack

- Frontend: vanilla HTML / CSS / JS (PWA-ready)
- Backend: Cloudflare Workers, Durable Objects, D1
- Deploy: GitHub Pages (UI) + Cloudflare (API)

## Local

Open `index.html` or serve the root. Point the client at your Worker endpoint when running the full stack.
